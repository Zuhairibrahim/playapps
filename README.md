## 📋 نبذة عن المشروع

**PlayApps** تطبيق ألعاب ترفيهي مبني بـ Flutter — ألعاب كلاسيكية بأسلوب عصري وأداء عالٍ، مع تجربة لعب سلسة على الهاتف، وإعلانات مدمجة بشكل أنيق لا يزعج اللاعب.

</div>

## 📋 About

**PlayApps** is a fun mini-games app built with Flutter — classic games with a modern twist, smooth mobile gameplay, and cleanly integrated ads that don't interrupt the fun.

## ✨ Features | المميزات

- 🐍 Classic Snake io-style gameplay | لعبة الثعبان بأسلوب عصري
- 🎯 Smooth landscape gaming experience | تجربة لعب أفقية سلسة
- 🏆 High performance 60fps | أداء عالٍ
- 📢 Smart native & banner ads | إعلانات ذكية مدمجة
- 🌍 Arabic & English friendly | يدعم العربية والإنجليزية

## 🛠 Tech Stack

`Flutter` · `Google AdMob` · `Custom Game Engine`

## ⬇️ Download & Run | التحميل والتشغيل

```bash
git clone https://github.com/Zuhairibrahim/playapps.git
cd playapps
flutter pub get
flutter run
```
